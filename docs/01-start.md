# Начало работы

Планировщик — веб-приложение для планировки квартир. В нём строят стены произвольной формы, получают комнаты с площадями и сразу видят всё в 3D. Все размеры в метрической системе.

## Запуск

Нужен Node.js 22 или новее. В терминале, в папке проекта `D:\dev\planner`:

```bash
npm install      # один раз: поставить библиотеки
npm run dev      # запустить приложение
```

Команда напишет адрес, обычно `http://localhost:5173`. Его нужно открыть в браузере. Пока сервер работает, изменения в коде сразу видны на странице. Остановить сервер — `Ctrl+C` в терминале.

### Если `npm run dev` не запускается

- **Ошибка `Missing script: "dev"`.** Команда запущена не в той папке. Перейдите в проект командой `cd D:\dev\planner`.
- **Ошибка `running scripts is disabled`.** PowerShell запрещает скрипты. Запустите `npm.cmd run dev` или переключите терминал VS Code на Git Bash.
- **Порт занят.** Vite возьмёт следующий порт, например `5174`. Откройте адрес, который он напечатал.

## Другие команды

| Команда | Что делает |
|---|---|
| `npm test` | автоматические тесты |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | сборка готового приложения в папку `dist` |
| `npm run docs` | собрать эту документацию в `docs/index.html` |
| `npm run shot` | снимок запущенного приложения через Edge |
| `npm run check:walls` | нарисовать комнату 6,55 × 3,40 «руками» через Edge и проверить перенос |
| `npm run check:projects` | проверить список проектов, перезагрузку, файл и удаление через Edge |

## Где хранятся данные

Проекты сохраняются в браузере сами (база IndexedDB), через полсекунды после каждого изменения. Их может быть сколько угодно — список открывается кнопкой с названием в шапке. Если очистить данные сайта в браузере, проекты пропадут, поэтому важное **сохраняйте в файл** (`Ctrl+S`) — его можно открыть на любом компьютере (`Ctrl+O`). Проект, который раньше лежал в `localStorage`, при первом запуске сам переезжает в список.
