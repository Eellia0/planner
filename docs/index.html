Начало работы

Планировщик — веб-приложение для планировки квартир. В нём строят стены произвольной формы, получают комнаты с площадями и сразу видят всё в 3D. Все размеры в метрической системе.

Запуск

Нужен Node.js 22 или новее. В терминале, в папке проекта D:\dev\planner:

npm install      # один раз: поставить библиотеки
npm run dev      # запустить приложение

Команда напишет адрес, обычно http://localhost:5173. Его нужно открыть в браузере. Пока сервер работает, изменения в коде сразу видны на странице. Остановить сервер — Ctrl+C в терминале.

Если npm run dev не запускается

  • Ошибка Missing script: "dev". Команда запущена не в той папке. Перейдите в проект командой cd D:\dev\planner.
  • Ошибка running scripts is disabled. PowerShell запрещает скрипты. Запустите npm.cmd run dev или переключите терминал VS Code на Git Bash.
  • Порт занят. Vite возьмёт следующий порт, например 5174. Откройте адрес, который он напечатал.

Где хранятся данные

Пока проект один, и он сохраняется в браузере сам при каждом изменении. Если очистить данные сайта в браузере, проект пропадёт. Список проектов и сохранение в файл будут на следующих этапах.

Интерфейс

Окно делится на четыре части:

Часть Что в ней
Сверху название приложения, переключатель вида «План · План + 3D · 3D», кнопки «Отменить» и «Повторить»
Слева инструменты: Выбор (V) и Стена (W). Буква в углу кнопки — горячая клавиша
В центре план на белом листе и 3D-вид. Их можно показать рядом или по одному
Справа панель свойств: название проекта, число помещений и общая площадь, свойства выбранного, параметры проекта, подсказки

План

  • Сетка: крупные линии через 1 м, мелкие через 10 см. Мелкие видны при приближении.
  • Колесо мыши меняет масштаб, точка под курсором остаётся на месте.
  • Правая или средняя кнопка мыши сдвигает вид.
  • Подписи вдоль стен — их длины в метрах. В центре комнаты — её название и площадь.

3D

  • Перетаскивание вращает камеру, колесо меняет масштаб, правая кнопка сдвигает вид.
  • Когда стен становится больше или меньше, камера сама вписывает всё построенное в окно.
  • Выбранные стены подсвечены зелёным, как и на плане.

Тема

Светлая или тёмная тема включается сама, по настройке системы. План всегда остаётся на белом листе, как чертёж.

Отмена

Любое действие отменяется: Ctrl+Z, повтор — Ctrl+Y или Ctrl+Shift+Z. Перенос мышью отменяется целиком одним шагом. Помнятся последние 200 действий.

Стены и комнаты

Как вводить размеры

Все длины можно вводить в любой записи:

Ввод Что значит
340 целое число без единиц — сантиметры: 3,40 м
3,40 или 3.4 дробное число без единиц — метры
340 см, 3,4 м, 3400 мм с единицей, по-русски или латиницей (cm, m, mm)

Точность — до миллиметра. Стены и проходы подписываются в метрах («6,55»), толщины — в сантиметрах («12 см»).

Рисование стен

  1. Включите инструмент Стена: кнопка слева или клавиша W.
  2. Кликните на плане первую точку. Если рядом есть угол, точка прилипнет к нему, иначе — к сетке через 5 см.
  3. Ведите мышь в нужную сторону. Направление прилипает к углам, кратным 15°.
  4. У конца рисуемой стены появится поле «Длина», курсор уже в нём. Наберите длину и нажмите Enter. Можно и просто кликнуть: длина возьмётся по мыши, с точностью до сантиметра.
  5. Продолжайте следующую стену от последней точки.
  6. Чтобы замкнуть комнату, кликните в первую точку цепочки, она подсвечивается зелёным.

Esc стирает набранную длину, повторный Esc заканчивает цепочку, третий переключает на «Выбор». Если длина набрана с ошибкой, поле краснеет и стена не ставится.

Комнаты

Замкнутый контур становится комнатой:

  • у неё есть название «Комната 1», «Комната 2» и площадь;
  • толщина всех её стен сама уходит наружу. Линия, по которой вы рисовали, — это внутренняя сторона стены. Квартиру меряют рулеткой изнутри, поэтому введённые размеры — это размеры комнаты, а площадь считается по внутренней стороне;
  • углы стыкуются «на ус», без щелей. Очень острые углы обрезаются прямо, чтобы стена не торчала далеко.

Толщина

  • Новые стены получают «Толщину новых стен» из параметров проекта, по умолчанию 12 см.
  • Толщину любой стены можно поменять в её свойствах.
  • «Толщина растёт»: у стены комнаты варианты «наружу», «внутрь» и «по центру», у отдельной стены — «в одну сторону», «в другую» и «по центру».

Свойства стены

  • Длина — по линии, на которой стену рисовали, у комнаты это внутренняя сторона. Новая длина двигает дальний конец стены, соседняя стена подстраивается.
  • Толщина и сторона толщины.
  • Удалить стену.

Если выбрано несколько стен, можно задать толщину сразу всем или удалить их.

Параметры проекта

  • Высота потолка — высота всех стен в 3D, по умолчанию 2,70 м.
  • Толщина новых стен.

Модель данных

Стены образуют граф:

  • узлы (nodes) — точки углов;
  • стена (walls) соединяет два узла a и b, у неё есть толщина thickness и сторона толщины side;
  • комната (rooms) — список узлов по порядку обхода.

Если сдвинуть узел, вместе с ним едут все стены, которые на нём сходятся.

Все длины хранятся в метрах, округлённых до миллиметра. Координаты плана: x вправо, y вниз, как на экране.

Сторона толщины

  • Нормаль «влево» от направления a→b — это perp(d) = (−dy, dx).
  • side = 1 — толщина слева, −1 — справа, 0 — поровну в обе стороны.
  • Линия стены — та, по которой её рисовали и измеряли.
  • При замыкании комнаты addRoom разворачивает толщину всех её стен наружу: площадь со знаком больше нуля означает, что внутренность лежит слева от обхода.

Стыки углов

wallOutline строит контур стены. У каждого узла стены сортируются по углу. Левая грань каждой стены встречается с правой гранью следующей по кругу, точка их пересечения и есть угол «на ус». Если угол выступает больше чем на 4 толщины (очень острый угол), стена обрезается прямо.

Состояние и отмена

  • В историю отмены (zundo) попадает только проект. Выбор, инструмент и черновик не отменяются.
  • Перенос мышью: пока тянут, в preview лежит копия проекта со сдвигом, и её рисуют план и 3D. При отпускании вызывается одно действие, и в историю попадает ровно один шаг. Хук useShownProject() возвращает черновик, если он есть, иначе проект.
  • После отмены цепочка рисования сбрасывается, а из выбора убирается всё, чего больше нет.
  • Автосохранение — localStorage, ключ planner.project.

План (SVG)

  • Внутри <g transform="translate scale"> всё рисуется в метрах.
  • Толщина линий не зависит от масштаба (vector-effect: non-scaling-stroke).
  • Размеры текста и белых обводок задаются через px = 1 / scale: единица внутри плана — метр, а не пиксель.

3D

  • Контур стены → THREE.Shape из точек (x, −y) → ExtrudeGeometry на высоту → поворот на −90° вокруг X. В итоге план (x, y) ложится в 3D как (x, высота, y).
  • Пол комнаты строится тем же способом через ShapeGeometry.

Проверки

  • npm test: единицы, стыки углов, площадь, перенос, рамка, удаление.
  • npm run check:walls при работающем приложении: рисует комнату вводом длин, замыкает, меняет толщину, выделяет рамкой, переносит группу и угол, снимает экран в D:\dev-tools\planner\.
  • Подводные камни:
    • снимки через флаги Edge --screenshot неверно меряют холст 3D, поэтому снимать только через скрипты Playwright;
    • Playwright набирает кириллицу без нажатий клавиш, поэтому в скриптах единицы пишутся латиницей.
