# Горячие клавиши

| Клавиша | Где | Действие |
|---|---|---|
| `V` | везде | инструмент «Выбор» |
| `W` | везде | инструмент «Стена» |
| `Ctrl+Z` | везде | отменить |
| `Ctrl+Y`, `Ctrl+Shift+Z` | везде | повторить |
| `Enter` | поле «Длина» | поставить стену набранной длины |
| `Esc` | рисование | стереть длину → закончить цепочку → перейти к «Выбору» |
| `Shift` + клик | выбор | добавить или убрать стену |
| `Ctrl+A` | выбор | выбрать все стены |
| `Delete` | выбор | удалить выбранное |
| стрелки | выбор | сдвинуть выбранное на 1 см |
| `Shift` + стрелки | выбор | сдвинуть на 10 см |
| колесо | план и 3D | масштаб |
| правая или средняя кнопка | план | сдвинуть вид |

Клавиши работают и в русской раскладке. Пока курсор стоит в поле ввода, буквы набираются в поле и не переключают инструменты.
