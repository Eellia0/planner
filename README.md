# Планировщик

Веб-приложение для планировки квартир: стены произвольной формы, мебель с параметрами, свои 3D-модели с масштабированием, план с размерами и 3D-вид. Всё в метрической системе.

Сейчас идёт этап 1 — **редактор стен**.

## Запуск

Нужен Node.js 22+.

```bash
npm install      # поставить зависимости (кэш npm задан в .npmrc — на диске D)
npm run dev      # открыть приложение в браузере с автообновлением
npm test         # тесты
npm run build    # сборка в папку dist
npm run shot     # снимок запущенного приложения через Microsoft Edge (для проверки глазами)
npm run check:walls  # нарисовать комнату 6,55 × 3,40 вводом длин и снять экран
npm run docs     # собрать документацию в docs/index.html
```

## Документация

Все функции, горячие клавиши, устройство кода и история изменений — в папке [docs](docs/). Сайт-документация: `npm run docs`, затем открыть `docs/index.html`.

## Стек

TypeScript, React, Vite; 3D — three.js через React Three Fiber и drei; состояние — Zustand + Immer, отмена действий — zundo; хранение в браузере — Dexie (IndexedDB); тесты — Vitest. Все библиотеки под лицензией MIT.

## Структура

```
src/
  core/      модель проекта и расчёты без интерфейса: единицы, геометрия стен, операции
  store/     состояние редактора, отмена действий, автосохранение
  plan2d/    план сверху (SVG) и инструменты рисования
  view3d/    3D-вид
  ui/        панели интерфейса
  App.tsx    каркас окна
scripts/     служебные скрипты (снимок экрана)
```

## Договорённости

- Все длины внутри — в метрах. Ввод: «106» и «106 см» — сантиметры, «1,06» и «1,06 м» — метры, «1060 мм» — миллиметры.
- Размер стены по умолчанию — по внутренней стороне, толщина наращивается наружу.
